# Phase 8 — AI 요약

시장·포트폴리오·브리핑 요약을 버튼 클릭 또는 인증된 API 요청으로 생성합니다. AI 학습, 매매 추천, 주문 기능은 포함하지 않습니다. 기존 가격 알림 엔진은 LLM에 의존하지 않습니다.

## 설정

.env에 GOOGLE_AI_STUDIO_API_KEY을 입력합니다. 기본 모델은 gemini-2.5-flash이며 GEMINI_MODEL로 변경할 수 있습니다. 키가 없으면 AI 요청은 503으로 안내하고 나머지 앱은 정상 실행합니다.

```sh
docker compose up -d --build --wait
```

워크스페이스 연결 후 대시보드 아래 'AI 시장 요약', 포트폴리오의 '내 포트폴리오 요약', '전체 브리핑 생성' 버튼을 사용합니다. 요약은 자동 실행되지 않으며 API 사용료가 발생할 수 있습니다.

## API

모든 경로는 기존 세션 또는 X-Monitor-Token 인증과 no-store 정책을 적용합니다.

- GET /agent/status: 키를 노출하지 않고 설정 여부 반환.
- POST /agent/market/:market: 해당 시장과 활성 알림 요약. 개인 자산 조회 없음.
- POST /agent/portfolio: 자산 평가액·비중·수익률, 관련 시장·알림 요약.
- POST /agent/briefing: 관심 종목·활성 알림·포트폴리오 종합 요약.

본문은 `{ "timeframe": "1h" }`이며 기본 주기는 1h입니다. 6개 캔들 주기를 지원합니다. 임의 프롬프트, 추가 필드, Discord 발송 옵션은 받지 않습니다. 자동 스케줄과 Discord 브리핑 전송은 Phase 9 범위입니다.

결과는 kind, summary, generatedAt, context를 포함합니다. context에는 실제 입력한 구조화 데이터와 누락/범위 제한 경고가 포함됩니다. 가격과 지표 시각이 다를 수 있으며 포트폴리오 24시간 수익률이나 제공되지 않은 변동성은 만들지 않습니다.

## 범위와 장애 처리

LLM_PROVIDER/LlmProvider 인터페이스로 provider를 교체할 수 있습니다. 현재 Gemini generateContent 고정 HTTPS endpoint, 출력 최대 4096 tokens, 호출 45초 timeout, 자동 재시도 없음으로 구현했습니다. 미완성·빈·거절 응답은 정상 요약으로 취급하지 않습니다. API 오류 원문과 키·입력·출력은 로그에 남기지 않습니다.

한 번에 앱 전체에서 요청 1개만 실행하고 시작 시점부터 최소 10초 간격을 둡니다. Bithumb 부하를 제한하기 위해 시장 분석은 최대 5개를 순차 조회합니다. 브리핑은 관심 종목→알림 종목→보유 자산의 가격 조회 시장 순으로 중복을 제거합니다. 알림은 최대 100개, 자산 세부는 최대 100개이며 잘린 범위는 경고합니다. 일부 시장/포트폴리오 조회 실패는 명시하고, 사용 가능한 시장·자산 데이터가 전혀 없으면 LLM을 호출하지 않습니다. 설정 DB 조회 실패도 오류로 반환합니다.

전송 데이터: 계산된 시장 분석, 알림 가격과 거리, 요청 종류에 따라 종목·평가액·비중·수익률. API 자격증명은 x-goog-api-key 헤더에서만 사용하며 분석 입력에 포함하지 않습니다. 계좌 식별자, 보유 수량, 원본 캔들은 분석 입력에서 제외합니다. 요약/컨텍스트는 DB나 브라우저 저장소에 저장하지 않습니다. 로그아웃·페이지/종목 변경 시 화면 결과를 비웁니다. Google의 데이터 보존·처리 정책은 API 계정 정책에 따릅니다.

## 검증

```sh
cd backend
npm test
cd ../frontend
npm run build
npm run test:e2e
```

모의 provider로 데이터 최소화, 누락 데이터, 요약 실패, 요청 제한, Gemini 응답 파싱, 비밀값 제거를 검증합니다. 브라우저에서는 설정 필요·명시적 실행·결과·실패 화면을 모의 응답으로 확인합니다. 실제 LLM 검증은 키와 모델 설정 후 별도로 필요합니다.

[Gemini 공식 문서](https://ai.google.dev/api/generate-content)를 기준으로 구현했습니다.

## 실측 결과 (2026-10-07)

Gemini 2.5 Flash로 실제 KRW-BTC 시장 요약 생성(HTTP 201)을 확인했습니다. 백엔드 테스트 56개와 브라우저 테스트 3개 통과. 개인 포트폴리오·브리핑은 모의 데이터로 검증했으며 실제 계좌 내용을 Gemini로 보내는 검증은 수행하지 않았습니다. Docker Backend/PostgreSQL은 healthy 상태입니다.
